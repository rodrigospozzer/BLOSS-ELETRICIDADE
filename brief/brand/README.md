# Brand Input

Esta pasta contém a fonte oficial da identidade visual do projeto.

Arquivo esperado:

manual-identidade.pdf

Este documento deve definir, quando disponível:

- diagnóstico da marca;
- posicionamento;
- conceito central;
- estilo visual principal;
- influência secundária;
- intensidade;
- sensações;
- protagonista visual;
- densidade;
- linguagem de formas;
- assinatura visual;
- paleta de cores;
- tipografia;
- fotografia;
- UI digital;
- direção de Hero;
- elementos a evitar.

## Regra

O Manual de Identidade é a SOURCE OF BRAND TRUTH.

Ele define COMO A MARCA DEVE SE EXPRESSAR.

Não utilizar este documento como fonte para inventar:

- serviços;
- endereço;
- avaliações;
- números;
- horários;
- dados corporativos.

Essas informações pertencem ao Perfil Corporativo.

## Arquivo

Nome obrigatório:

brief/brand/manual-identidade.pdf
