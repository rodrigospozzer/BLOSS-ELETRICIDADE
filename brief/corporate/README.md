# Corporate Input

Esta pasta contém a fonte factual oficial da empresa.

Arquivo esperado:

perfil-corporativo.pdf

O documento deve reunir, quando disponíveis:

- nome da empresa;
- descrição;
- história;
- serviços;
- produtos;
- diferenciais reais;
- endereço;
- área atendida;
- Google Maps;
- telefone;
- WhatsApp;
- e-mail;
- redes sociais;
- horários;
- equipe;
- avaliações;
- depoimentos;
- certificações;
- garantias;
- processo de atendimento;
- perguntas frequentes;
- informações úteis para SEO local.

## Regra

O Perfil Corporativo é a SOURCE OF FACTUAL TRUTH.

Ele define O QUE É VERDADE SOBRE A EMPRESA.

Nunca inventar fatos ausentes.

Quando uma informação não estiver disponível:

registrar como ausente ou solicitar ao responsável pelo projeto.

Não preencher por inferência.

## Arquivo

Nome obrigatório:

brief/corporate/perfil-corporativo.pdf
